Conversor de Unidades y Monedas
pagina web que convierte unidades de medida y monedas. Hecho con HTML, CSS y JavaScript
Funcionalidades

*Conversor de Unidades*:
Longitud (km, m, cm, mm, millas, yardas, pies).
Peso (kg, g, mg, lb).
Capacidad (l, ml).
Temperatura (°C, °F, K).
*Conversor de Monedas*
Consulta los valores en tiempo real usando la API pública de open.er-api.com.
Si no hay internet o falla la red, usa como respaldo los datos de jason.json.
*Botón para invertir los valores origen y destino (⇄)*.
*Cálculo automático al escribir o cambiar los selectores.*
*Diseño adaptable para celular y computadora.*

Archivos del proyecto
* index.html: Estructura de la página y las vistas.
* estilo.css: Estilos visuales.
* java.js: Lógica de navegación, cálculos y llamadas a la API.
* jason.json: Archivo local con datos y tasas de cambio si no hay red.

Como usarlo

1. Abrir el archivo index.html en el navegador.
2. Elegir si usar el conversor de unidades o el de monedas.
